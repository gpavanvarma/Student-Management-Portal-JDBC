# Student Management Portal - JDBC

A simple **Student Management Portal** implemented in **Java JDBC**, **MySQL** and **HikariCP Connection Pooling**.

It is a **command-line based CRUD application** which shows how a Java application can connect to MySQL database effectively using connection pooling and how a Java application can manage database transactions effectively using **transaction and rollback**.

## 🚀 Features

- Add new student
- View all students
- Get student by id
- Update student
- Delete student
- MySQL database integration
- JDBC PreparedStatement
- HikariCP connection pooling
- Transactions
- Commit
- Rollback
- Menu driven command-line interface
- Exception handling
- Separate application and database layers
